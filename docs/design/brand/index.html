Visual identity

Heat, held in three rings.

The Server Curio mark is a heat gradient. Plum at the cool outer ring, rose through the middle, crimson where the metal is worked, and three sand-coloured sparks thrown clear. Rackmarshal takes its whole palette from that object — no colour in this system was invented beside it.

01 · Colour

The brand ramp

Five values read straight from docs/images/logo.svg, plus the off-white they sit on. These six are fixed. Everything else in the system is derived from them.

Anvil #15090E Dark ground
Plum #4D1229 Outer ring · primary action
Rose #993744 Middle ring · tagline
Ember #B61F33 Spiral · critical only
Spark #F7BB7A Highlight fill · never text
Quench #FAF7F5 Light ground
Ember is not the action colour.

Crimson is the brand's loudest value and also the universal colour of failure. Using it for primary buttons would make every page look like an incident. Plum carries actions; ember is reserved for the mark and for genuinely critical state.

03 · State

Rackmarshal's own vocabulary

Two ramps exist because Rackmarshal has two things it must always show: which environment you are looking at, and whether an endpoint matches its desired state.

Endpoint drift

The four values rackmarshal-provisioner stores in endpoint_status (0011). Colour never carries the meaning alone — the word is always present.

in_sync drifted failed unknown

Environment tier

Every authenticated surface shows its tier, because an operator with four profiles open needs to know which one they are about to retire an endpoint in. A stripe, not a fill — the tier is ambient context, not an alert.

05 · The mark

The lockup, and the symbol alone

docs/images/logo.svg is the canonical lockup with the Rackmarshal wordmark and tagline. docs/images/logo-mark.svg is the same paths with the wordmark removed, for square and small-format uses. Their path data must stay byte-identical.

Mark The three rings and their sparks. Holds the full ramp.
Wordmark “Server” in Ember, “Curio” in Plum. Drawn as paths — never live text.
Tagline Open Sans 500 in Rose. The one element that changes between repositories.
The tagline is the only part that varies.

Sibling repositories share this mark and change the tagline text alone — here it reads “Rackmarshal Infrastructure Management”. The mark and wordmark never change with it, and the wordmark is path data, so it is never re-set in a font or retyped.

Which to use

The lockup wherever Rackmarshal introduces itself and there is room for it to be read — a README, a login page, a document cover, a slide. The symbol alone wherever it must be recognised rather than read: favicons, avatars, a collapsed sidebar rail, an app icon. Minimum width for the lockup is 240 px; below that the tagline stops being legible and the symbol should be used instead.

06 · Product mark

Rackmarshal has its own mark

The Server Curio mark above identifies the company. The hammer and anvil identifies Rackmarshal, one product within it. They are used in different places and are never locked up together: a surface carries one or the other, never both side by side.

rackmarshal-mark.svg · Plum, Rose · on Quench

rackmarshal-mark-dark.svg · Quench, Spark · on Anvil

These are a pair, not one adaptive file.

Unlike the tokens, the mark does not adapt by itself — the light file carries Plum and Rose, the dark file Quench and Spark. Pick the file that matches the ground. A light mark on a dark surface is the single most common way to get this wrong. Ember appears in neither icon: it stays reserved for critical state, so a masthead or favicon never reads as an alert.

The lockup

One horizontal lockup pairs the icon with the wordmark, in each theme. The wordmark is outlined path data in the supplied asset, so nothing depends on an installed font.

The wordmark is two-tone, the same move the Server Curio wordmark makes with “Server” and “Curio”: “Rack” takes the hot value, “marshal” the deep one. The accent flips by theme because neither value survives both grounds — Spark measures 1.59 on Quench and Ember 3.00 on Anvil — so Spark stands in for Ember on dark, exactly as --focus already does.

rackmarshal-lockup.svg · 857 × 256 · Ember 6.09, Plum 13.73

rackmarshal-lockup-dark.svg · 857 × 256 · Spark 11.46, Quench 18.27

The icon has a floor at 32 px.

The rack indicators simplify as the mark is reduced, and below 32 px a dedicated simplified favicon is preferable to shrinking this one. The lockup sets its own floor: under roughly 200 px wide the wordmark stops being legible, so use the icon alone instead.

07 · Iconography

Adopted, plus what no library has

The generic vocabulary comes from Lucide (ISC, 1600+ icons) on a 24 × 24 grid with a 2 px currentColor stroke and round caps — the same round terminals the mark's rings end in. Six Rackmarshal concepts have no reasonable stand-in, so they are drawn to that exact geometry.

agent The daemon on a managed host
plugin A process the agent launches
directive-bundle The signed envelope agents pull
environment The trust domain and its identity
enrollment-token Single-use credential for a host
drift Applied state diverged from desired

Optical weight holds across sizes

A 2 px stroke drawn for 24 px reads heavy at 16 px, so the stroke thins as the icon does. Below 16 px an icon is not used at all.

An icon may stand alone. A state may not.

Icon-only controls are allowed where space is tight — toolbars, a collapsed rail, a dense table's action column — each with an accessible name, a tooltip, and a 44 × 44 hit area. But drift and tier always render their word, because icon shape is no more readable than colour to someone who has not learned the set, and Retire, Revoke and Delete keep their labels at every width.
